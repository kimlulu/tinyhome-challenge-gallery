# Tiny Home Design Challenge — Submission Gallery

188 submissions from the Vizcom Tiny Home Design Challenge, browsable in one page.

- Every card image is embedded in `index.html`, so the grid loads instantly with no external requests.
- Full-resolution images and animations stream from Google Drive when a submission is opened.
- Pin submissions to build a shortlist; the shortlist is stored in the URL, so copying the address bar shares it.

Entrant email addresses have been removed from this public build.
